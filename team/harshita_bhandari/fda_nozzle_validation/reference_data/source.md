The Re = 500 Sudden Expansion dataset was selected because the initial
capstone FDA-nozzle CFD benchmark uses the corresponding low-Reynolds-number,
laminar configuration.

The experimental dataset is retained separately from the CFD predictions so
that the reference measurements are not modified during processing.
