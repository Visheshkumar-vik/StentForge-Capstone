# Validation Plots

This folder will contain processed plots comparing the CFD predictions against
the FDA/OSEL-DAM experimental measurements.

Planned figures include:

- experimental vs CFD centreline axial velocity
- experimental vs CFD radial velocity profiles
- experimental vs CFD pressure distribution
- percentage-error summary where appropriate

Experimental data and CFD results should be shown distinctly and all axes must
include units.

Plots will only be generated after confirming that the experimental and CFD
coordinates represent equivalent physical locations.
